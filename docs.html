Introduction

Moon Hosting is a bot and app hosting platform. Deploy your Discord bot, Telegram bot, Node.js app, Python script, website or database — all from one panel, with no server management.

How it works

Moon Hosting runs your code inside isolated containers on our infrastructure. You push your code (via GitHub or file upload), set your environment variables, and Night keeps your process online — restarting it automatically if it crashes, taking rolling backups, and streaming logs to your panel in real time.

Quick start

The fastest way to deploy is from a GitHub repository:

# 1. Connect GitHub in the panel
# 2. Import your repository
# 3. Set DISCORD_TOKEN in environment variables
# 4. Click Deploy

✓ Build complete (2.1s)
✓ Container started
Logged in as YourBot#0001 — 3 guilds

Environment variables

Sensitive values like bot tokens and API keys go into environment variables. Mark them as secret to mask them in logs and hide them from the panel UI. Night injects them into your process at runtime — you access them the same way as on your local machine:

// Node.js
const token = process.env.DISCORD_TOKEN;

# Python
import os
token = os.getenv("DISCORD_TOKEN")

Supported runtimes

  • Node.js — v20, v22 (LTS). Supports npm, yarn and pnpm.
  • Python — 3.11, 3.12. Supports pip and requirements.txt.
  • Java — JDK 21. Maven and Gradle supported.
  • Go — 1.22+. Standard go build toolchain.
  • Rust — Stable channel. Cargo supported.
  • PHP — 8.3. Composer supported.
