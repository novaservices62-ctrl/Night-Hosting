Setup

Online in three steps.

No server, no SSH, no process manager. If it runs on your machine, it runs here.

01

Bring your code

Connect a GitHub repository (public or private), upload a zip archive, or start from a community template. Night pulls your code and builds it.

02

Add your secrets

Tokens and API keys go into environment variables. Mark them secret — they're masked in logs and never exposed to other users or deployments.

03

It stays online

Your process starts, is restarted automatically if it crashes, backed up as it changes, and its logs stream in real time straight to your panel.

FAQ

Questions, answered.

Is it really free?
Yes. The free plan gives you 256 MB of RAM, 25% of a CPU core and one deployment, with no credit card required. You renew it from the panel every 4 days so free resources go to bots that are still in use.
Which languages can I use?
Node.js, Python, Java, Go, Rust and PHP are fully supported. Databases (MySQL, PostgreSQL, MongoDB, Redis) and one-click services (static sites, PHP sites) all run on the same account and share the same resource pool.
Can I host something other than a Discord bot?
Absolutely. Telegram bots, Node.js and Python apps, websites, REST APIs, scripts and databases all run on the same account. Night is built for bots first but it's really a general-purpose hosting platform.
What happens if my bot crashes?
It is restarted automatically and the full log stays in your console. The AI log reader can read the output and explain what went wrong in plain words, even on the free plan.
Can I deploy from a private GitHub repository?
Yes. Connect your GitHub account and import any public or private repository. You can also upload a zip archive or start from a blank deployment and push files through the panel.
Do you offer a refund?
We offer a 7-day money-back guarantee on all paid plans, no questions asked. After that, refunds are handled case by case. Contact support and we'll sort it out.
